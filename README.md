## ①制作サイトのタイトル
チーズアカデミーTOKYO

## ②制作サイトの説明（40文字程度）
チーズ職人養成学校受講生募集サイト

## ③工夫した点・こだわった点
- ヘッダーを固定
- ヘッダーメニューにカーソル当てた時の色付け
- ヘッダーメニューから該当箇所へ動かす
- ギャラリーを矢印ボタンで無限ループ
- ニュースの写真にカーソル当てると少しズーム
- ブラウザに表示するアイコン設定
- スマホ対応（ハンバーガーメニュー、縦積み）

## ④難しかった点・次回トライしたいこと（または機能）
日本語・英語の切り替えをできるようにしたかったのですが、a. ページを2つ用意する、b. 日英で各パート用意しておき表示切り替えできるようにする、c. API連携するの3択出てきて、今回はそこで止まってしまいました。

## ⑤備考（感想、シェアしたいことなど、何でも）
普段何気なく利用しているサイトの動きが、どのように構築されているのかを知る機会になって、なるほどーの連続でした。

特にgoogle mapの画像埋め込み時には、あの使い方わからない機能はこのためだったのか！と、何だかエンジニアの世界に少しだけ足を踏み入れた気分に勝手になっていました。サイト画面収録機能も初めて使いました（エンジニアから共有される側は経験していた）。

p2pにも初参加して話しましたが、工夫点のアイデア出しも含めてAIの便利さを一層体感し、自身のスキル習得とのバランスを考える課題でした。
